## 0.1.0 (2026-08-26)

First public release. barra turns a Google Pixel 8a (akita) into a headless Linux node
whose Tensor G3 accelerators are programmable directly.

### Features

* Seven kits: LLM chat, speech recognition, speaker diarization, text-to-speech,
  wake word, image generation and a kernel workbench.
* Setup fetches everything itself: base image, kernel, Magisk and the kit artifacts from
  this release; third-party models pinned from their original sources.
* Every shipped artifact has its source, license and obligations documented in
  [docs/models.md](docs/models.md).

### Known limitations

* The first-time download of Google's factory image (building `super.img` with `lpmake`)
  is unchanged legacy code and has not been exercised end to end.
